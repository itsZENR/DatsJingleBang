# DatsJingleBang — архив участия в геймтоне

Бот для соревнования DatSteam с игрой в стиле Bomberman: управление несколькими юнитами,
установка бомб, разрушение препятствий и взаимодействие с соперниками.

## Что находится в проекте

- Поиск маршрутов BFS, оценка опасных зон и выбор целей для бомб.
- Память исследованной карты при тумане войны.
- Расчёт цепных взрывов и координация целей нескольких юнитов.
- API-клиент с ограничением частоты запросов и настройками стратегии в JSON.
- [Визуализатор](visualizer.html) и [просмотр истории раундов](history.html).

Код пакета находится в `bomberman/bomberman/`; описание подхода — в [STRATEGY.md](STRATEGY.md).
Сохранены также исходный `bot_old.py` и заметки о рефакторинге.

## Запуск

Проверка импорта выполнена на Python 3.11.

```bash
python -m pip install -r requirements.txt
export DATSJINGLEBANG_TOKEN="your-game-token"
cd bomberman
python -m bomberman.main
```

В PowerShell переменная задаётся командой `$env:DATSJINGLEBANG_TOKEN="your-game-token"`.
Флаг `--prod` выбирает production URL из конфигурации. Локальный сервер визуализации работает на `localhost:8888`.

## Ограничения исходного решения

Автоматизированных тестов в исходном архиве нет. В планировании побега сохранена проблема:
поиск пути запрещает промежуточные клетки будущего взрыва и может отвергать существующий путь отхода.
Пути записи логов ботом и их чтения визуализатором также требуют согласования.
Эти особенности задокументированы, игровая логика при публикации не исправлялась.

## Статус архива

Сохранённый снимок хакатонного решения. Активная разработка и поддержка не планируются.
Публикация сохраняет рабочие материалы, включая экспериментальные и незавершённые части.
Игровые серверы организаторов могут быть недоступны; архив не обещает совместимость с их текущим API.
Токены и локальные настройки исключены. Сведения о составе архива — в [ARCHIVE.md](ARCHIVE.md).

## Полный архив

[Release с исходниками и дополнительными материалами](https://github.com/itsZENR/DatsJingleBang/releases/tag/archive-2026-10-22) содержит:

- `source-history.bundle` — Git-историю исходников и сохранённый рабочий снимок;
- `artifacts.zip` — дополнительные исходные материалы, не включённые в основную ветку;
- `SHA256SUMS.txt` — контрольные суммы файлов.

Чтобы восстановить дополнительные файлы, распакуйте `artifacts.zip` в корень клонированного репозитория.
Пути внутри архива соответствуют исходной структуре проекта. Локальная папка `.git`, кэши и настройки помощника в него не входят.

Для этого проекта `artifacts.zip` содержит все 15 исходных JSONL-логов раундов.
